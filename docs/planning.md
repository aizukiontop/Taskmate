# TaskMate — Planning Documents

## Project overview

TaskMate is a task management application for students and busy individuals.

## Features

- Add, edit, complete, and delete tasks
- Filter tasks by All / Active / Completed
- Data persists in PostgreSQL (or localStorage in demo mode)

## Target users

Students and busy individuals who want a simple, distraction-free way to organize their daily tasks.
